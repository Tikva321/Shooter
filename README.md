Shooter
Космический шутер на Pygame. Управляйте ракетой, сбивайте вражеские НЛО и не дайте им прорвать оборону.

Управление

Стрелка влево / вправо - движение
Пробел - выстрел

Механики

Ограниченный боезапас (5 патронов)

Перезарядка (2 секунды)

Счётчик сбитых врагов

Счётчик пропущенных врагов

Три условия окончания игры:
Победа - 10 сбитых врагов
Поражение - 5 пропущенных врагов
Поражение - столкновение с врагом

Необходимые файлы

galaxy.jpg - фон
rocket.png - игрок
ufo.png - враг
bullet.png - пуля
space.ogg - фоновая музыка
fire.ogg - звук выстрела

Запуск

python main.py

Требования

Python 3.x
Pygame

pip install pygame
